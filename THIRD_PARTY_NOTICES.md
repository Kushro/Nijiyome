## 4. Services

No usage-tracking or crash-reporting SDKs (enforced by `contracts/test/guard.test.mjs`). There is no own backend and no own login.
The app contacts:

- Metadata and lists: AniList (GraphQL + OAuth), MyAnimeList (REST + OAuth), ani.zip, Kitsu, Shikimori, MangaDex, MangaUpdates, trace.moe (image search), AniSkip (intro / outro markers).
- Releases: api.github.com (update notice).
- Only when the user sets them up: debrid services (TorBox at `api.torbox.app`, recommended; Real-Debrid, AllDebrid and Premiumize, experimental; the API key only ever goes to its own service, over HTTPS), subtitle translation endpoints (Google, DeepL, Azure, OpenAI-compatible), cloud text-to-speech (OpenAI, ElevenLabs), the KittenTTS download on desktop (repo1.maven.org for ONNX Runtime, huggingface.co for the model; both pinned by SHA-256), Stremio addons (and Cinemeta for their ids), extension repositories and an extension server.
- Hosts allowed by the installed extensions, per their manifest permissions.
- BitTorrent trackers, DHT and peers when a torrent source is used.
- A paired PC on the local network (Nijiyome Link, including the watch-history sync).

This list is maintained by hand; the source code is the reference.
